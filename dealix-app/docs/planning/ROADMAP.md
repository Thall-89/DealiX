# DealiX Roadmap

## Current focus

This roadmap tracks the working operating-system-style experience for DealiX and the next improvements that matter most for real PC flipping workflow.

## Implemented now

- Build detail pages for each major build, including editable mock data and local browser storage
- Global search bar and Ctrl+K command palette
- Task management system with real current tasks
- Notification center UI
- Motherboard compatibility assistant for Legacy Powerhouse
- Build health and status placeholders for future scoring

## In progress

- Better build health score explanations
- More complete build photo sections
- More detailed benchmark data entry
- Richer notifications and task linking

## Planned

- AI Deal Score from 0 to 100
- Live marketplace scanning
- Price trends and profit trends by month
- Expense tracker and invoice tools
- Barcode and QR labels
- Storage mapping and inventory import
- AI listing generator and negotiation assistant
- Supabase, real marketplace APIs, and live AI providers
